# Professional Profile — Chao Liu

Personal portfolio with Career Bridge Map and Recruiter Fit Report (JD Matcher).

## Tech stack

- **Frontend:** React + Vite + TypeScript + Tailwind CSS
- **API:** Vercel serverless functions in `api/`
- **AI:** DeepSeek (server-side only)

## Local development

### Frontend only

```bash
npm install
npm run dev
```

Open http://localhost:5173 — static UI loads; JD Matcher needs API routes.

### Full stack (frontend + API)

```bash
npm install
npx vercel dev
```

Set `DEEPSEEK_API_KEY` in `.env` or when prompted by Vercel CLI.

### Legacy local Express server (optional)

```bash
npm run start:local
```

Uses `server/` — not used on Vercel.

## Build

```bash
npm run build
```

Output: `dist/` (generated by Vite, not committed).

## Vercel deployment

**Project settings:**

| Setting | Value |
|---------|--------|
| Framework Preset | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |
| Root Directory | *(leave blank)* |

**Environment variables** (Vercel Dashboard → Settings → Environment Variables):

```
DEEPSEEK_API_KEY=your_real_key_here
```

Optional (local TLS issues only):

```
DEEPSEEK_TLS_INSECURE=0
```

Do **not** set `VITE_DEEPSEEK_API_KEY`. The API key must never reach the browser.

## API routes

| Route | Method | Purpose |
|-------|--------|---------|
| `/api/jd-match` | POST | Generate Recruiter Fit Report |
| `/api/jd-match-remaining` | GET | Daily remaining count |

## Security

- DeepSeek is called only from `lib/fitReport.js` (used by `api/jd-match.js`)
- Frontend calls `/api/jd-match` via `fetch` only
- Never commit `.env`

## Project structure

```
api/                  Vercel serverless API routes
lib/                  Server-only helpers (DeepSeek, profile data)
src/                  React frontend
server/               Optional local Express (not used on Vercel)
attached_assets/      Profile photo
public/               Resumes (resume-en.pdf, resume-zh.pdf)
```

## Content sources

- **Live website copy** is defined inline in `src/pages/Home.tsx` (`CONTENT` object).
- `src/content/en.ts` and `src/content/zh.ts` mirror the same structure for type reference and future refactors; keep them in sync with `Home.tsx` experience entries when updating resume content.
- **PDF paste-ready copy** for Apple Pages: `pdf-experience-copy.md`
